# Anno 1800 — Українська локалізація

Фанатський проєкт команди **DailygamersVIP** з перекладу гри *Anno 1800* українською мовою.  
Мета — створити якісну, автентичну локалізацію без русизмів та кальок, щоб зробити гру доступною для українських гравців.

---

## 📂 Структура репозиторію
- `/original/` — оригінальний текст з гри (не змінюється).
- `/machine/` — машинний переклад (базовий варіант).
- `/translated/` — готові шматки від перекладачів.
- `/dictionary/` — словник термінів (узгоджені варіанти).
- `/localizer/` — програма для роботи з файлами локалізації (доступ лише команді).

---

## 🔄 Процес роботи
1. Перекладачі отримують машинний переклад і редагують свої блоки.
2. Кожен зберігає свій шматок у папку `/translated/`.
3. Важливо: у фіналі мають бути всі **ID текстів** (порядок не має значення).
4. Редактор переглядає переклади, затверджує й додає у фінальний файл.
5. Узгоджені терміни додаються у `/dictionary/`.

---

## 📖 Dictionary
Для термінів та стилістики використовуємо канал **#dictionary** у Discord.  
Там ми пропонуємо варіанти перекладу, обговорюємо й затверджуємо єдиний варіант.

---

## 🤝 Команда
- **Перекладачі** — адаптують машинний переклад.
- **Редактори** — затверджують і слідкують за єдністю стилю.
- **Координатор (DailygamersVIP)** — розподіляє тексти, дає інструкції, збирає фінальний файл.
